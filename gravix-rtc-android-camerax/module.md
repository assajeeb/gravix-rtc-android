# Module gravix-rtc-android-camerax

CameraX support for Gravix Android SDK. This library provides an CameraX integration for use with
the Android Gravix SDK, providing access to more camera functionality such as custom zoom and torch
control.

# Package org.webrtc

The core Gravix CameraX package.

# Package com.gravixcloud.rtc.camerax.ui

Easy to use UI utilities for controlling the camera.
