# Module gravix-rtc-android-sdk

Android client SDK for [Gravix Cloud](https://www.gravixcloud.com) real-time audio and video rooms.

# Package com.gravixcloud.rtc

This package contains the initial `connect` function.

# Package com.gravixcloud.rtc.compose

Utilities and composables for use with Jetpack Compose.

# Package com.gravixcloud.rtc.room

Room is the primary class that manages the connection to the Gravix Room. It exposes listeners that
lets you hook into room events.

# Package com.gravixcloud.rtc.room.track

`AudioTrack` and `VideoTrack` are the classes that represent the types of media streams that can be
subscribed and published.
